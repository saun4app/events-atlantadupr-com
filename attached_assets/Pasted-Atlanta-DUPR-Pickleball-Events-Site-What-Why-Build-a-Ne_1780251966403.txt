Atlanta DUPR Pickleball Events Site
What & Why
Build a Next.js full-stack event registration web app for Atlanta DUPR Pickleball Events. Players browse events and sign up; organizers and admins manage everything from a role-gated admin panel.
Member list
Create atl_dupr-meber_list with fields: dupr_id (unique), player_name, double_rating (text), double_reliability (int 0–100), single_rating (text), single_reliability (int 0–100), self_rating
Admin only — only Admin role can perform CURD operations on atl_dupr_member_list.
Events — public
Public homepage lists all upcoming events with name, date, location, format type, and rating type
Two round robin event types:
Fixed-partner: players register as a pair; partner info collected at signup
Rotating-partners: players register individually
Each event detail page shows: description, format, rating type, signup window status, approval requirement notice (if approval required), and a participants list
Participants list on event detail page — columns: Name, DUPR Rating, Self-Rating (only shown/populated when DUPR rating is NR or non-numeric), roster status (confirmed / waitlisted / pending approval)
Signup
Member signup: prompt for DUPR ID only → look up in atl_dupr_member_list → submit registration
For fixed-partner events both forms also collect partner’s DUPR ID.
Signup is only open between signup_start_datetime and signup_end_datetime
If approval required: registration lands in a "Pending Approval" state; Admin/Organizer must approve before the player appears on the confirmed roster
If approval not required and event is not full: registration is immediately confirmed
If event is full: registration goes to waitlist (regardless of approval setting)
Event creation (admin/organizer)
Full-featured event creation form with:
Clone from existing event — dropdown to select an existing event and pre-fill all fields
Event start date/time and end date/time
Event location — location name and street address
Repeating events — toggle to enable recurrence:
Frequency: Daily, Weekly, or Monthly
Number of occurrences
Preview list of all generated dates for confirmation, individual editing, or deselection (Luma-style)
Each occurrence saved as its own record linked by a series_id
Rating type — DUPR Rating required (toggle on/off)
Participant limits — minimum and maximum number of participants
Waitlist — toggle on/off
Signup window — signup start (default: now) and signup end (default: 12 hrs before event start)
Require approval — toggle on/off; when enabled, all registrations start as "Pending Approval" and must be manually approved by Admin or Event Organizer before being confirmed
Admin panel (role-gated)
Three navigation sections:
Manage Events (Admin + Event Organizer)
List all events; create, edit, end (close registration), and remove events
Per-event roster: columns Name, DUPR Rating, Self-Rating (when NR/non-numeric), Status (Confirmed / Waitlisted / Pending Approval)
Full CRUD on participants: add manually, edit details, remove, promote from waitlist
Approve/reject pending registrations when event has approval required
Manage Members (Admin only)
Sortable/searchable table of atl_dupr_member_list
Full CRUD: add member, edit any field, delete member
CSV upload to atl_dupr_member_list
Clear all data of atl_dupr_member_list
Manage Users (Admin only)
Add new users (name, username, password, role), delete users, view user list
User roles
Admin — full access to all 3 admin sections
Event Organizer — Manage Events only
Event Participant — public site only (no admin panel)
Event Captain — Manage designated event(s)
Court leader — Manage designated event(s)
